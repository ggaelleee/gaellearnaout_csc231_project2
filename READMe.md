The Last Gate

Gaelle Arnaout CSC 231 Project 2

The Last Gate is a 2D platformer set in a castle. You play as a little knight who jumps across gaps, rolls past hazards, and faces a skeleton guard on the way to the final gate. Collect coins and reach the gate to complete the level.

Controls

| Key | Action |
| --- | --- |
| A / D or Left / Right Arrow | Move |
| Space | Jump |
| Left Shift | Roll |
| Esc | Pause |
